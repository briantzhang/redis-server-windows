# Redis for Windows 5.0.14.1-bp53

本轮将本地 RDB 格式版本从 9 提升到 10，作为后续格式演进的基线：

- `RDB_VERSION` 提升为 10；保存的 `dump.rdb` 与 DUMP payload 都写入版本 10。
- 加载器继续接受版本 1 到 10，原有版本 9 快照和 bp49 的流计数扩展仍可读取。
- 版本 9 中引入的本地流计数扩展继续使用哨兵长度编码，不新增对象类型，保持旧数据兼容。
- 回归新增 1 项，覆盖 RDB 魔数、DUMP 版本号以及 RESTORE 往返；全量共 123 项。

只提供 Windows x64 构建，未 push、未打包、未发布。
