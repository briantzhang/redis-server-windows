# Redis for Windows 5.0.14.1-bp18

以 tporadowski/redis `v5.0.14.1`（提交 `ec77f72dc`）为底座的 Windows x64 单机版，选择性回移 Redis 6.0–7.2 的命令能力。不是 Redis 官方 6、7 或 8 发行版；`redis-server --version` 报告 `v=5.0.14.1-bp18`。

本版在 bp17 之上改了 Windows 网络层：完成端口的收发放到多个线程。没有新增命令。

## 相对 bp17 的改动

### 多 IO 线程

- 事件循环之外再起 3 个线程阻塞在同一个 I/O 完成端口上。完成包只会投递给其中一个等待者，所以每个线程只处理自己取到的套接字状态。
- 完成端口的并发线程数从 1 改为 0，由系统按处理器数量调度，不再把所有完成压到一个线程。
- IOCP 请求用的私有堆去掉 `HEAP_NO_SERIALIZE`。多个线程同时投递和完成重叠请求时，不串行化的堆会损坏。

命令的解析、执行和回复仍然只在主线程上进行。这不是 Redis 6 的 `io-threads`：没有把读缓冲、写缓冲或命令执行分摊出去，只是把完成通知的收取并行化。

## 不包含

RESP3、Functions、TLS、多段 AOF、新版 RDB、集群、Sentinel、客户端内存驱逐。没有引入 Redis 8 源码。只有 Windows x64。

## 验证

80 项黑盒回归在多 IO 线程开启的构建上全部通过，使用独立临时目录和随机端口，不连接现有实例。
