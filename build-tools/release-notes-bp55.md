# Redis for Windows 5.0.14.1-bp55

本轮补齐列表随机采样命令：

- 新增 `LRANDMEMBER key [count]`：随机返回元素但不修改列表。
- 不传 `count` 时返回单个元素或 nil；正数 `count` 返回不重复元素，超过列表长度时截断；负数 `count` 返回 abs(count) 个元素，允许重复。
- `count 0` 返回空数组，非法参数和错误类型返回相应错误。
- 回归新增 1 项，覆盖空列表、正负计数、无重复/可重复、列表不变与错误路径；全量共 125 项。

只提供 Windows x64 构建，未 push、未打包、未发布。
